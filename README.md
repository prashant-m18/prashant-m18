## 🚀 Featured Projects

### 🛒 [Cartify — Multi-Vendor E-Commerce Platform](https://github.com/prashant-m18)

A multi-vendor e-commerce platform with a responsive storefront, vendor dashboard, and admin panel.

**Tech Stack:** Next.js, JavaScript, Tailwind CSS, Redux Toolkit

- Built interfaces for customers, vendors, and administrators.
- Implemented state management for orders, inventory, and commissions.
- Focused on responsive design and application performance.

### 📋 Gradient — Enterprise Task Management System

A task management platform designed around Admin, Manager, and Employee roles.

**Tech Stack:** React, JavaScript, Supabase, Tailwind CSS

- Designed role-based dashboards and task assignment workflows.
- Developed deliverable submission and review workflows.
- Planned portfolio tracking, file attachments, and task-level discussions.

### 🖥️ Linux Server Monitoring Dashboard

A web dashboard for monitoring system health and resource utilization.

**Tech Stack:** Python, Flask, psutil, Bootstrap, Chart.js

- Monitors CPU, memory, disk, network, and running processes.
- Provides REST API endpoints for system metrics and health information.
- Presents performance data through a responsive dashboard.

### 💰 Personal Expense Tracker

An offline expense-tracking application developed during a summer research internship.

**Tech Stack:** Python, SQLite, Matplotlib

- Supports expense recording, categorization, and keyword-based search.
- Generates monthly summaries and budget insights.
- Visualizes spending patterns using charts.
